Why it starts on your device

The key that identifies your account is stored locally. A Community Node is not your account owner or home server.

Connectivity prefers direct P2P, then relay-supported P2P, and uses relay fallback only when the earlier paths cannot carry the data.

A moderation event is optional trust input from its issuing node, not a command applied to the whole network. Each client decides how to use it.

Getting started

  1. Download and run the installer for your platform
  2. Pick a language, confirm you are 18 or older, and accept the app terms
  3. Review and accept the Community Node documents
  4. Set up your profile
  5. Open a topic, post, and reply
  6. Create or join a private channel inside the same topic

No network connection starts until you accept. NSIS installers distributed on GitHub are not OS code-signed, so Windows may show a warning.

FAQ

Is there a macOS version?

No package is provided at this time. Only Windows 10/11 and Linux (x86_64 GUI, x86_64/aarch64 CLI).

Can I recover a lost account?

There is no central reissue or recovery. Export the key that identifies your account as an encrypted string, or keep a device backup yourself.

Is a Community Node required?

A node is not used until you accept its documents. If you choose "Later", you can return to consent from Explore or Settings. A node is not where your posts are stored.

Why can't I search?

Connectivity assistance and search (Community Index) are separate. If a node does not provide search, choose another node that does.

The NSIS installer from GitHub shows a warning

NSIS installers distributed on GitHub are not code-signed for the OS. Check the release notes before running the installer. In-app updates verify the signed manifest.

Is my data kept after an update?

Updates are expected to keep your key, profile, follows, posts, local database, Iroh data, Community Node settings, private-channel access, and notification inbox. Take a backup before uninstalling or resetting.

Where do I report problems?

Use "Send feedback" in the app's bottom bar, or GitHub Issues / Discussions. For connectivity, update, and recovery problems, attach a diagnostic report from developer mode.

Are there features in development?

Live, Game, Stream, and Metaverse Domes are hidden by default. They are experimental and appear only after enabling developer mode in Settings -> Developer, with no backward-compatible decoding or migration guarantee for their data formats.
