kukuri は Windows と Linux のデスクトップアプリです。このページを PC で開いてダウンロードしてください。

3分で試す手順を見る

テスター向けの Builder Preview（v0.3.0-preview.2）です。一般向けの安定版ではありません。

macOS 版はありません。Windows 10 / 11 または Linux（x86_64）でお試しください。

話題から始まって、会話が続き、小さな輪へ

3 つの場面は、既定で使える機能だけでできています。登場する人物と会話はデモです。

1

話題を選ぶ

最初から用意された話題を開くか、コミュニティインデックスで話題と投稿を検索します。検索を提供するのは、あなたが同意したコミュニティノードです。

2

公開で会話する

投稿し、返信し、スレッドで続けます。リアクション、リポスト、引用、ブックマークも同じ画面で行えます。

3

同じ話題の中で、小さな輪へ

タイムライン上部の「プライベートチャンネル」から作成・参加します。話題を離れずに、招待限定・相互フォロー限定・相互フォロー+のいずれかの範囲で話せます。

選べること

初期値のまま始められて、必要なところだけ変えられます。

選べるもの初期値変えるとどうなるか
コミュニティノード配布時の候補が 1 件（同意前は未使用）同意したノードだけが接続支援・検索・moderation を提供します。同意しなければ使いません。
プライベートチャンネルの公開範囲招待限定相互フォロー限定、相互フォロー+に変えると、参加できる相手の条件が変わります。
テーマdarklight に変えると、明るい配色に切り替わります。
表示言語OS の表示言語（未保存時）日本語 / English / 简体中文を選べます。保存した言語は次回起動でも優先されます。
成人向け表示非表示設定 → 安全 で許可すると、成人向けラベル付きの投稿が表示されます。
開発者モード無効設定 → 開発者 で有効にすると、実験中の機能と診断レポートが現れます。

あなたの端末が起点である理由

アカウントを識別する鍵は端末内にだけ保存されます。コミュニティノードはあなたのアカウントの持ち主でも、ホームサーバーでもありません。

接続は Direct P2P を優先し、次に Relay Supported P2P、実データが relay を経由する Relay Fallback は、ほかの経路が成立しないときだけ使います。

moderation の判定は、それを出したノードからの任意の入力であり、ネットワーク全体への命令ではありません。受け取り方は各クライアントが決めます。

始め方

  1. 自分の環境向けのインストーラーを取得して起動する
  2. 言語を選び、18 歳以上であることを申告し、アプリ規約に同意する
  3. コミュニティノードの文書を確認して同意する
  4. プロフィールを設定する
  5. 話題を開いて投稿・返信する
  6. 同じ話題の中でプライベートチャンネルを作る・参加する

同意するまでネットワーク接続は始まりません。preview installer に OS のコード署名はなく、Windows では警告が出ることがあります。

よくある質問

macOS 版はありますか

現時点でパッケージを提供していません。Windows 10 / 11 と Linux（x86_64 GUI、x86_64 / aarch64 CLI）のみです。

アカウントを失ったら復旧できますか

中央での再発行・復旧はありません。アカウントを識別する鍵を暗号化してエクスポートするか、端末バックアップを自分で保管してください。

コミュニティノードは必須ですか

各ノードの文書へ同意するまで利用しません。「あとで」を選んでも、見つける／設定から後で同意へ戻れます。ノードは投稿の保管先ではありません。

検索できないのはなぜですか

接続の手助けと検索（コミュニティインデックス）の提供は別です。検索を提供しないノードでは、別の検索提供ノードを選んでください。

インストール時に警告が出ます

preview installer に OS のコード署名がないためです。リリースノートを確認してから実行してください。アプリ内更新の manifest は署名を検証します。

更新するとデータは残りますか

鍵、プロフィール、フォロー、自分の投稿、端末内データベース、Iroh のデータ、コミュニティノード設定、プライベートチャンネルの閲覧権限、通知一覧が保持される想定です。アンインストール・リセットの前にはバックアップを取ってください。

不具合はどこへ報告しますか

アプリ下部バーの「フィードバックを送る」、または GitHub Issues / Discussions へ。接続・更新・復旧の問題には、開発者モードで取得した診断レポートを添えてください。

開発中の機能はありますか

Live、Game、Stream、Metaverse Dome は既定で非表示です。設定 → 開発者 で開発者モードを有効にしたときだけ現れる実験機能で、データ形式の後方互換・移行は保証しません。
