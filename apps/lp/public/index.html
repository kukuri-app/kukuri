よくある質問

どの環境で使えますか

ブラウザ版はインストール不要で、パソコンの Chrome・Firefox・Safari と Android の Chrome で動作を確かめています。アプリ版は Windows 10 / 11 と Linux（x86_64）向けで、macOS・iOS・Android のアプリはありません。端末全体のバックアップなど、アプリ版だけの機能があります。

はじめるときに必要なことは

最初に、18歳以上であることの申告とアプリ規約への同意が必要です。同意するまでネットワークへの接続は始まりません。コミュニティノードは、その文書を読んで同意したものだけを使います。

アカウントはどこに保存されますか

アカウントを識別する鍵は、使っている端末（ブラウザ版はそのブラウザ）にだけ保存されます。中央での復旧はできないので、設定から鍵を暗号化して書き出し、保管してください。
