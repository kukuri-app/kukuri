- Surface / user / purpose: `Settings > Reactions` の「リアクションのセット」と、投稿・DM の本文の共有用の文字列。自作・保存済みのカスタムリアクションをまとめて人に渡したい人と、受け取って自分も使いたい人が、画像＋検索名が同じリアクションを同じリアクションとして使えるようにする（#1232 D3、ADR 0017 §2.6）。
- Summary:
  - 自作のカードにも保存済みと同じ選択のチェックを置き、自作・保存済みから選んだもの（最大 100 件。同じ識別は 1 件）と名前で「選んだ N 件でセットを作る」。101 件以上を選ぶと warning の Notice を出し、作るボタンを押せない。保存済みの「選択した項目をクリア」は、選んだ保存済みだけを外す。
  - 作ったセットは新しい順に 100 件まで一覧に示し、行ごとの「共有用の文字列をコピー」で `kukuri:reaction-set:<hash>` をコピーする（既存のコピーの通知を出す）。
  - 投稿の本文の共有用の文字列は、既存の参照の chip と同じ形の「リアクションのセットを取り込む」ボタン（`smile-plus`）にする。DM の本文は、この文字列だけをボタンにし、他の参照は今どおり文字のまま示す。
  - 押すと右下の通知で「取り込んでいます…」（neutral。結果が出るまで消さない）→「「名前」から N 件を保存済みに加えました。」（自分で作ったものを除いたときはその件数も。accent）、取れないときは「取り込めませんでした…」（destructive）を示し、結果の通知は 6 秒で消える。コピーの通知とは同じ右下の列に縦に並べ、重ねない。
- Conditions:
  - Platform: Windows の Chromium（Playwright）で、ブラウザ mock の開発サーバー（`VITE_KUKURI_DESKTOP_MOCK=1`）
  - Viewport: 1280×860（設定は 1280×1500）、390×860（設定は 390×1500）
  - Theme: light / dark
  - Locale: ja / en（zh-CN は i18n の parity の試験で鍵と placeholder を確認）
  - State: 投稿・DM のボタン、取り込みの完了・失敗の通知、設定の選択中・作成後の一覧。101 件以上の選択は Vitest
- Accessibility / interaction: 取り込みのボタンは `button` で、accessible name は表示の文言（Vitest・Playwright の role 検索で確認）。投稿の本文（`role="button"`）の中でも、押下は投稿を開かずに取り込みだけを行う（既存の参照の chip と同じく伝播を止める）。通知は `role="status"`・`aria-live="polite"`。自作のカードのチェックの accessible name は保存済みと同じ「<検索名> を選択」。390px では名前の欄が最小 12rem を保ち、作るボタンは次の行へ折り返す。
- Performance: 取り込みが読むのはセットの blob 1 件で、保存済み・投稿の件数によらない（app-api の試験で docs の読取り数が増えないことを確認）。作ったセットの一覧は設定のリアクションの section を開いたときに 1 回だけ読み、新しい順の 100 件の窓で読む。画面側の保存済みの一覧は app-api と同じ 200 件の窓に収める。
- Validation: Vitest（`ReactionsPanel.sets.test.tsx` の作成・上限・コピー、`SmartReferenceText.reactionSet.test.tsx` の投稿・DM のボタン、`DesktopShellPage.reactions.test.tsx` の投稿からの取り込みの成功・失敗と設定の保存済みへの反映、`internalLinks.test.ts` の共有用の文字列の解析）、Storybook の `Settings/ReactionsPanel` `WithSets`、eslint、tsc、i18n の parity。
- Not verified: 実機（Windows・Linux の desktop と実ブラウザの Web）での 2 アカウント間の取り込みの通し。取り込みの往復（同じ ID のまま保存され、同じリアクションとして数えられる）は app-api の 2 アカウントの試験で確かめた。撮影の mock では設定のタイルの画像が出ず、頭文字の表示で撮った（タイルの表示は今回変えていない）。
