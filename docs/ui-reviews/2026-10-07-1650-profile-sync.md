- Surface / user / purpose: アカウントメニューの使用中のアカウントの行と「プロフィールの端末間同期」Dialog。同じアカウントを 2 台の端末（native・Web）で使う本人が、両方の端末で押して、プロフィール・フォロー・フォロワー・投稿などを両端末の和集合にそろえる（移行の後にフォロー・フォロワーが 0 件、公開投稿が少なくなった端末を直す）。
- Summary: [2026-09-13 の record](./2026-09-13-account-menu.md) のアカウントメニューと、[移行の画面](./2026-10-04-1211-account-transfer-history.md)に次を足した（2026-10-07 ユーザー判断。ADR 0062 §9）。
  - 使用中のアカウントの行の右端（チェックの右）に、icon-only の「プロフィールの端末間同期」（`refresh-cw`、ghost）。tooltip と accessible name は同じ操作名。使用中でない行には出さない（同期できるのは起動中のアカウントだけ）。行の切替のボタンとは別のボタンにした（入れ子の操作にしない）。
  - 押すと同じ名前の Dialog を開いて待ち受ける。もう一方の端末でも押すことの案内、残り時間、合わせるもの・合わせないもの。つながったら受けた項目・投稿の件数を状態の文で示し、投稿を受ける間は「同期をやめる」（secondary）を置く。
  - 完了は移行と同じ accent の Notice に、受けた投稿の数、相手に無かった本文・添付の数、途中で止まったときは両方の端末でもう一度押すと続きから同期することを示す。失敗は理由（期限切れ・中止・保存できない・接続が切れた・始められない）の Notice（destructive）と「もう一度試す」。
  - Dialog を閉じる操作（×・Escape・外側）は同期を止める（移行の待ち受けと同じ）。
- Conditions:
  - Platform: Linux/Chromium の mock の build（Playwright。待ち受けから完了までの状態は mock の時計で進めた）
  - Viewport: 1280×844、1024×844、390×844
  - Theme: light / dark
  - Locale: ja / en / zh-CN
  - State: メニュー（tooltip の表示）、待ち受け、項目の同期中、投稿の同期中、完了（投稿の途中で止めた結果は Vitest）、失敗（Vitest）
- Accessibility / interaction: 同期のボタンは `role="menuitem"` で、行の切替のボタン（`menuitemradio`）から下の矢印で届く（Playwright で keyboard の到達と Enter、pointer の hover の tooltip を確認）。閉じたら menu の入口へ focus を戻す。keyboard で開いた Dialog の最初の Escape は閉じるボタンの tooltip を閉じる（既存の Dialog と同じ）。残り時間は `role="timer"`、進みは `role="status"`。
- Performance: 待ち受けの間だけ 500 ms ごとに状態を読む（移行と同じ）。同期の送受信は背景の task で 64 件の page ごとに進み、画面の操作を待たせない。menu の表示のために他のアカウントの通信を起動しない。
