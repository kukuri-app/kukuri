## Game SDK native library

The Game SDK DLL and Sidecar statically link libvpx 1.17.0 (BSD-3-Clause, with the
WebM additional patent grant) for VP8. The source is the `v1.17.0` tag of
https://chromium.googlesource.com/webm/libvpx. The license and the patent grant are
`libvpx-LICENSE.txt` and `libvpx-PATENTS.txt` in this `docs/licenses/`, and the Game SDK
UPM package includes them under `Documentation~`.
