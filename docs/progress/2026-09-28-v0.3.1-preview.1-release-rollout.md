## 不具合と修正

- **症状**
  - 投稿の見出し（署名つき envelope）は届くが、本文（テキスト blob）が「取得に失敗しました」のまま表示されない。
  - 再取得ボタンでも取れない。
- **原因**
  - 表示中の欠けた本文を取り直す `recover_missing_bodies` が、node の取得を旧い projection の締切で打ち切っていた（Windows・CI は 5 秒、他の OS は 2 秒）。
  - peer 1 候補の接続待ちも 5 秒ある。そのため、取得先の先頭の peer が応答しないと、次の peer を一度も試さずに終わっていた。
  - v0.3.0 では取得先の候補を最大 4 台に絞って並べるため、この状態が続いた。
- **修正**: [#1391](https://github.com/kukuri-app/kukuri/pull/1391)（区分 C）。
  - 締切を node の取得の総予算 `DISPLAY_FETCH_TIMEOUT`（30 秒）にした。
  - 表示の呼び出しが待つのは従来どおり 300ms だけで、取得は背景で続く。
- **修正前の再現**: test `a_body_delivered_after_an_unresponsive_first_peer_is_recovered` が、修正前の main で FAIL し、修正後に PASS した。
- **独立監査**: PR head `33e5bf43` で PASS（blocker 0 件）。記録は #1391 のコメント。
- **版の同期**: [#1392](https://github.com/kukuri-app/kukuri/pull/1392)（区分 A）。
  - 公開済みの 0.3.0 の端末へ updater で届けるため、0.3.1 へ上げた。
  - 構成は #1386 と同じ。lockfile は自前 package の version だけが変わった。
