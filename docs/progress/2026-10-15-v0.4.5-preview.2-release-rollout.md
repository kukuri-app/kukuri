## preview.1 の停止（#1834）

- [Release run 38685613145](https://github.com/kukuri-app/kukuri/actions/runs/38685613145) の `linux-package / linux-appimage` で、Real app tests の `live`・`live-relay` が描画の時間切れで失敗し、公開前に止まった。配布用の build は Ubuntu 22.04（WebKitGTK 2.50.4・GStreamer 1.20）で、#1800 の試験が 22.04 で動いたのは初めてだった。
- 原因: WebKitGTK 2.50 では `<video>` から作った `VideoFrame` の encode が `EncodingError` になる。Linux の配信はこの経路で frame を作っていた。[PR #1835](https://github.com/kukuri-app/kukuri/pull/1835) で canvas を通す形にし、#1834 は Close。
- 同じ日の main の windows-fast（`6c767c22` の live）と PR #1835 の windows-fast（smoke）は、実アプリの試験の時間切れで 1 回ずつ失敗し、再実行で成功した。差分外の揺れとして扱った。
