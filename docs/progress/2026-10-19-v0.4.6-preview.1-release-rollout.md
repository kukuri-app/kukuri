## Web の WASM の大きさ（#1884）

- main `997653347`＋版の同期の tree の配布 build で、WASM が 29,233,346 bytes になり、Cloudflare Pages の 1 file の上限（25 MiB）を超えて `cargo xtask web-build` が失敗した。0.4.5 は 23,798,473 bytes で、Web へ Live（moq、#1879）が入って増えた。CI は配布 build を流さない。
- 操作者の判断で、`web-release` を大きさ優先（`opt-level = "s"`）にした。鍵の導出（argon2id 64 MiB・3 回）は wasm32 の V8 で 5 回の中央値が 3 で 138 ms、s で 144 ms、argon2・blake2 だけ 3 に戻しても 148 ms で、crate ごとの上書きは入れなかった。
- main `ce08e5dd` の配布 build の WASM は 20,563,707 bytes（gzip 7.8 MB）、artifact は計 23,855,406 bytes。
