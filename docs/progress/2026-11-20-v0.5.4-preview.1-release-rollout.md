## 新旧の版の互換

v0.5.3-preview.1 から通信に影響し得る変更は、依存更新（#2089）だけだった。それ以外は試験・CI・Game SDK の Sidecar の修正。依存の差分を読み、新旧の端末が Community Node 経由でつながることを確かめた。

- relay: frame の定義・`/relay` の path・protocol の版は同じ。
- QUIC: noq-proto の frame・transport parameter は同じ。
- gossip・docs・blobs: ALPN と protocol の定義は同じ。
- Live（moq）: 版の交渉と catalog は同じ。
- 公開 blob の補助 index: protocol のソースは同じ。
- 非互換は、新しい版から古い `cn-addr-index` への DHT の書込みだけ。
